Gmail

  1. Ozubené kolečko → Zobrazit všechna nastavení.
  2. Karta Obecné → sekce Podpis → Vytvořit nový.
  3. Do pole vložte podpis (Ctrl+V / Cmd+V).
  4. Dole klikněte na Uložit změny.

Outlook

  1. Nastavení → Účty → Podpisy (v aplikaci: Soubor → Možnosti → Pošta → Podpisy).
  2. Nový podpis, pojmenujte ho „create4you“.
  3. Vložte podpis (Ctrl+V) a nastavte ho jako výchozí.
  4. Uložte.

Apple Mail

  1. Mail → Nastavení → Podpisy.
  2. Vyberte účet a klikněte na +.
  3. Vypněte „Vždy použít výchozí písmo zprávy“ a vložte podpis (Cmd+V).
  4. Zavřete okno – uloží se samo.
